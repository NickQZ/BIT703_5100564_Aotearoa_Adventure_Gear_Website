# BIT703_5100564_Aotearoa_Adventure_Gear_Website

I was tasked with creating a mock front-end website for Open Polytechnic's BIT703 Web Technologies course.

# Executive Summary

Aotearoa Adventure Gear is a premium outdoor equipment retailer catering to adventure enthusiasts across New Zealand. The goal of this project was to build a fully responsive, multi-page front-end website that balances informative static content with dynamic, personalised shopping interactions.

The website simulates a real e-commerce user journey:

- Home page

- Shop page

- Product detail page

- Shopping cart

- Shipping details

- Payment options

This project required integrating UI design, front-end logic, JavaScript validation, and user-friendly navigation.

# Project Overview

This assessment demonstrates the development of a fully functional e-commerce front end using modern web technologies. Users can browse products, view details, add items to a cart, enter shipping information, and choose payment methods. JavaScript is used heavily for dynamic page behaviour, form validation, and cart logic.

# Learning Objectives

This project demonstrates competency in:

- Building responsive multi-page websites using the Bootstrap framework

- Writing clean, modular JavaScript for validation and interaction

- Implementing custom form validation and feedback

- Designing user-friendly structures with semantic HTML

- Creating consistent branding using CSS

- Managing simple client-side state (cart items, totals)

# Key Features Implemented
- Product Display & Navigation

- Product cards styled with Bootstrap

- Product detail pages with imagery, pricing, and descriptions

- Clear, consistent navigation menu

- Back To Top Button for improved usability

- Hover underline affect on navigational links

- Product Carousel on index.html (home page)

- Add to cart Animation and Pop-up notification

# Interactive Shopping Cart

- Automatic updates to total (*Only if manually changed inside HTML document!)

- Free shipping automatically applied when total exceeds $600

# Form Validation

Custom JavaScript validation across:

- Shipping details

- Payment selection

- Credit card information

- Real-time error messaging using .is-invalid and Bootstrap feedback UI

- Prevents progression until forms are correct

# Payment Simulation

- Dynamic credit card field visibility

- “Pay Now” button includes optional alert informing users that functional flow ends here (mock site requirement)

# Fully Responsive Design

- Mobile-first layout

- Bootstrap grid for consistent scaling

- Tested across standard screen sizes

# Technical
Languages & Tools Used

HTML – Page structure

CSS – Site styling

JavaScript – Interactivity & validation

Bootstrap Framework – Responsive layout and UI elements

# Known Limitations (Intentional for Assessment)

- No backend/database (front-end only, as required)

- Payment gateway is simulated for demonstration purposes

- Cart data resets on refresh (client-side only)

- Static product data, not dynamically loaded from a database

- No persistent user accounts

These limitations align with the assessment outline.

# Running the Project

- No installation or dependencies required.

- Download or clone the project.

- Open index.html in any modern browser (Local only).
